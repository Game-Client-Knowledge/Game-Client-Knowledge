# 策划面经

策划面经用于沉淀真实面试题、追问路径和参考回答。建议原始问题和参考答案分开维护，先模拟作答，再复盘表达结构。

## 使用方式

按公司、年份、批次和岗位创建目录，例如：

```text
planning/interviews/company/2026-system-designer/README.md
planning/interviews/company/2026-system-designer/01-first-round.md
planning/interviews/company/2026-system-designer/01-first-round-answers.md
```
