# 威胁模型与常见作弊

## 防作弊保护什么

先定义资产和失败后果：

| 资产 | 典型损害 |
|---|---|
| 对局公平 | 自瞄、透视、加速、无后坐力、非法技能 |
| 经济资产 | 复制物品、重复领奖、非法交易、支付欺诈 |
| 隐藏信息 | 敌方位置、战争迷雾、牌库、掉落和匹配信息 |
| 账号身份 | 盗号、撞库、会话劫持、代练和账号交易 |
| 服务可用性 | 恶意请求、资源消耗、房间破坏和拒绝服务 |
| 排名与生态 | 演员、胜负交易、炸鱼、机器人和工作室 |

不同资产需要不同证据标准。竞技误判可能毁掉一场比赛，经济误判可能直接造成财产纠纷。

## 信任边界

```text
玩家输入：不可信
客户端进程与本地文件：不可信
玩家设备时间与环境报告：可作为信号，不是事实
网络：可能被观察、丢弃、重放和篡改
服务器权威状态：核心可信边界
运营配置和内部工具：高权限，同样需要审计
```

平台签名、硬件证明和受保护执行环境能增强信号，但不能消除被攻破、转发、自动化或账号滥用的可能。

## 状态修改类

常见目标：

- 生命、护盾、弹药和资源；
- 移动速度、重力、碰撞和时间倍率；
- 技能冷却、攻击间隔和动画锁；
- 本地存档、脚本配置和掉落结果。

根因通常是客户端拥有不该拥有的决定权，或服务器只接受结果而不验证过程。

防御重点：

- 服务器维护权威状态；
- 客户端发送输入/请求，不直接提交最终结果；
- 验证状态机转移、资源守恒和时间窗口；
- 本地存档不能作为线上资产权威；
- 关键结果可回放、回滚和追缴。

## 代码与运行时篡改

攻击者可能修改客户端二进制、脚本、资源或运行时行为，也可能通过外部工具观察和影响进程。

防御目标不是假设“检测到所有修改”，而是：

- 保证官方分发产物可验证；
- 提高静态和动态修改成本；
- 识别异常模块、环境和完整性状态；
- 将信号上传服务端参与风险判断；
- 即使客户端被修改，服务器仍拒绝非法结果。

不要在文档和日志中泄露具体检测规则、偏移、签名和阈值，这些属于敏感运营配置。

## 信息作弊

典型表现：

- 透视、ESP、地图全开；
- 读取战争迷雾外单位；
- 提前知道隐藏牌、掉落、刷新点或匹配对手；
- 观战窥屏和数据挖掘。

最有效的防御是**不下发不该知道的数据**：

- AOI/Relevancy 和可见性裁剪；
- 隐藏信息只在服务器保存；
- 对近边界对象做延迟、模糊或最小字段下发；
- 观战增加延迟并限制视角；
- 资源文件不包含可提前解锁的敏感结果。

如果客户端必须拥有完整数据，反篡改只能提高读取成本，无法形成绝对保密。

## 输入辅助与自动化

常见表现：

- 自瞄、自动开火和后坐力补偿；
- 高频宏、连点、自动技能组合；
- 自动寻路、刷怪、采集和交易；
- 无人值守机器人；
- 多开和设备农场。

它们可能不修改游戏状态，只生成“合法格式但不自然”的输入，因此单靠完整性检查无法覆盖。

防御需要组合：

- 服务器约束旋转、射速、动作和资源；
- 分析输入与命中行为的时间序列；
- 比较玩家自身历史和相似分段群体；
- 使用回放、举报和人工复核；
- 对高风险账号施加验证、降权、隔离或交易限制。

固定阈值容易误伤高手，也容易被低强度作弊规避。

## 协议与接口滥用

常见类别：

- 重放已成功的领奖/购买请求；
- 修改实体 ID、数量、价格或目标；
- 越权调用未在 UI 暴露的接口；
- 伪造时间、输入序列和客户端状态；
- 高频请求、并发竞态和顺序漏洞；
- 使用旧版本协议绕过新规则。

防御：

- 会话认证与消息完整性；
- Nonce/序列号和重放窗口；
- 服务端从权威配置读取价格和奖励；
- 幂等 Key、事务和唯一约束；
- 权限、对象归属和状态前置条件检查；
- 每账号/设备/IP/接口的多层限流；
- 协议版本和能力灰度。

## 经济、账号与社交作弊

不仅是客户端外挂：

- 多账号搬砖、工作室和资源转移；
- 代练、账号共享、盗号和交易；
- 胜负交易、演员、串通和恶意掉分；
- 退款欺诈、支付回调伪造；
- 利用漏洞复制物品或重复结算。

需要账号、设备、支付、交易和比赛关系图共同分析。单局行为正常不代表整个账号网络正常。

## 漏洞滥用

Bug Abuse 与传统外挂的区别是攻击者可能完全使用官方客户端，但组合出非法收益：

- 重复领取；
- 断线/并发触发重复结算；
- 卡地形或异常碰撞；
- 状态切换顺序绕过消耗；
- 跨服/跨场景复制。

治理顺序：

1. 立即阻断继续获利；
2. 保存影响范围和证据；
3. 修复服务端不变量与事务；
4. 回溯资产流向并按政策追缴；
5. 区分误触、普通利用和组织化滥用。

## 风险分级

| 风险 | 例子 | 优先策略 |
|---|---|---|
| 可直接预防 | 非法速度、重复领奖 | 服务端拒绝，不依赖事后封禁 |
| 可高置信检测 | 不可能状态、无权限请求 | 阻断 + 记录 + 分级处置 |
| 需统计判断 | 自瞄、机器人、演员 | 多局证据、模型、回放 |
| 高误伤风险 | 高水平操作、共享设备 | 风险控制与人工复核 |
| 高隐私成本 | 设备深度扫描 | 必要性评估、透明告知和最小采集 |
