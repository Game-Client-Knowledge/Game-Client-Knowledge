# 输出合并与画面呈现速记

## 测试与写入

输出阶段综合覆盖、深度、模板、混合和写掩码，把片元结果写入 Render Target。

- 深度测试决定是否通过，深度写入决定是否更新 depth；二者独立。
- 不透明物体通常开测试/写入并前向后排序；透明物体通常开测试、关写入并后向前排序。
- 模板缓冲可标记像素区域，常用于轮廓、遮罩和复杂光照路径。

## 混合

常见 Alpha 混合：`C = Cs * As + Cd * (1-As)`。预乘 Alpha 将颜色预乘覆盖率，边缘过滤更稳定，混合因子也不同；资源和 Shader 必须一致。

普通 Alpha 混合与绘制顺序相关，排序只能近似处理相交透明物体。OIT 可改善正确性，但增加内存和计算。

## 抗锯齿

| 方法 | 优点 | 代价 |
|---|---|---|
| SSAA | 质量高、通用 | 成本极高 |
| MSAA | 改善几何边缘 | Render Target/带宽；Shader/透明锯齿有限 |
| FXAA | 便宜、易集成 | 模糊，缺少时域信息 |
| TAA/TSR | 稳定亚像素与重建 | ghosting、历史失效、运动矢量依赖 |

## HDR、颜色与 Present

线性空间做光照，纹理按用途解码 sRGB；HDR 结果经曝光、Tone Mapping 和显示编码。Gamma/Linear 混用会导致光照和混合错误。

交换链管理可显示图像。双/三缓冲允许 CPU/GPU/显示并行；VSync 抑制撕裂但可能增加等待和延迟。更多在途帧提升吞吐，也增加输入延迟和资源占用。VRR 改善显示节奏但不消除游戏自身卡顿。

“一帧完成”可指 CPU 提交完、GPU 执行完或真正扫描显示，回答性能/延迟前先明确口径。
