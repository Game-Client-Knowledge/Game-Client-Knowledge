# 系统、网络与游戏数学速记

## 内存与 CPU

- 虚拟地址经页表/TLB 映射物理页；page fault 可能触发磁盘或按需分配，成本远高于普通访问。
- 栈是线程执行上下文的一部分，堆由 allocator 管理；“栈快”主要来自分配模式和局部性，不是物理介质不同。
- Cache line 是传输与一致性单位；连续数据、可预测访问和减少工作集通常比抽象 O(1) 更关键。
- false sharing：线程修改同一 cache line 的不同变量，仍导致缓存行来回失效。
- 内存池降低特定尺寸分配成本和碎片，但增加常驻内存、线程同步与生命周期复杂度。

## 并发

| 机制 | 适合 | 风险 |
|---|---|---|
| mutex | 保护复合不变量 | 竞争、优先级反转、死锁 |
| atomic | 简单状态/计数与无锁协议 | 内存序、ABA、活锁，不等于业务事务 |
| condition variable | 等待条件变化 | 虚假唤醒，必须用谓词循环 |
| semaphore | 资源/并发额度 | 容量与取消管理 |
| job system | 大量短任务和依赖图 | 粒度、调度开销、数据竞争、主线程汇合 |

数据竞争在 C++ 中是 UB。死锁四条件：互斥、持有并等待、不可抢占、循环等待；常用治理是固定锁顺序、缩短临界区、避免持锁回调和超时诊断。

## 网络

- TCP 提供有序可靠字节流，不保留消息边界；需应用层 framing，并面对队头阻塞。
- UDP 提供报文但不保证送达/顺序/唯一；可靠、拥塞、分片和安全由应用层或上层协议处理。
- 游戏协议要定义序列号、ack、超时、重传、幂等、压缩、版本和限流。
- 弱网关注 RTT、jitter、loss、reorder 和 bandwidth，不只看平均延迟。
- 客户端不可信；鉴权、重放保护、输入校验和资产权威必须在服务端闭环。

## 向量、矩阵与旋转

- 点积：投影、夹角、朝向；叉积：垂直方向与有向面积，结果受坐标手性影响。
- 变换顺序不可交换；明确行/列向量、左/右乘和坐标系约定。
- 法线在非均匀缩放下使用逆转置矩阵，不能直接套模型矩阵。
- 四元数避免欧拉角万向节锁，适合旋转组合与插值；仍需归一化，并处理 q 与 -q 等价。
- `Slerp` 角速度更均匀，`Nlerp` 更便宜；选择取决于质量和规模。

## 几何检测

- AABB 快但旋转后不贴合；OBB 更精确、检测更贵；Sphere 旋转不变。
- Ray/Plane、Ray/AABB、SAT、Closest Point 要说明坐标空间和数值容差。
- Broad phase 减少候选对，Narrow phase 做精确检测；物理查询性能首先受候选规模影响。
- 浮点比较、近平行、退化三角形和极端尺度是常见边界。
