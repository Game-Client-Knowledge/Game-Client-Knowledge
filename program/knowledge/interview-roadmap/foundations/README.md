# 计算机基础复习

## 面试目标

基础题不是术语竞赛。面试官通常借它确认：对象存在哪里、谁拥有、访问成本如何、并发何时正确，以及这些机制如何进入游戏的一帧。

## 内容

1. [语言、运行时与数据结构](./01-language-runtime-and-data-structures.md)：C++/C#/Lua 生命周期，容器与游戏算法。
2. [系统、网络与游戏数学](./02-systems-network-and-math.md)：内存/Cache/并发、传输协议、向量矩阵与几何。
3. [内存与并发模拟题](../02-os-memory-concurrency-mock-interview.md)：将孤立知识放回战斗系统场景。

## 高频主线

```text
对象生命周期 -> 内存布局 -> Cache/分配
-> 线程与同步 -> Job System
-> 网络输入/状态 -> 游戏同步
-> 坐标/旋转/几何 -> 物理与渲染
```

## 回答底线

- 复杂度之外补充数据规模、局部性和分配行为；
- 线程安全之外补充生命周期、内存模型与取消；
- TCP/UDP 之外补充消息语义、弱网和应用层协议；
- 数学公式之外补充坐标空间、数值误差和实际用途；
- 所有结论都能落到一帧中的生产者、消费者和同步点。
