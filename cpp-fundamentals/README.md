# C++ 基础知识

## 1. 文档范围

本文档整理 C++ 语言基础知识，按**标准版本归类**，覆盖以下主题：

- C++98：多重继承与 mix-in 类、RAII 与作用域守卫、内存分配器、模板特化与类型特征。
- C++11：统一初始化、标准属性说明符、Lambda 表达式、函数类型擦除（`std::function`）、`std::bind` 与引用包装。
- C++14：通用 Lambda、变量模板。
- C++17：`std::apply`。

> 适用方向：Unreal、自研引擎、渲染和性能相关岗位；同时为阅读 ECS 与面试知识库提供语言层基础。

## 3. 关于 C++03

C++03 是一次修订性标准：**没有新增主要语言特性**，只修复 C++98 的缺陷并小幅修订标准库。

因此本文不单列 C++03 章节，C++98 与 C++03 视为同一语言基线。

## 5. 阅读结论

掌握本模块时应抓住四个重点：

1. **C++ 的多数机制在编译期定型**：模板实例化、类型特征匹配、Lambda 展开都没有运行时解析成本。
2. **RAII 是资源管理的统一答案**：分配器上下文、锁、句柄都依赖"析构必定执行"。
3. **C++11 是分水岭**：统一初始化、属性、Lambda、类型擦除让"泛型能力"与"运行时多态"可以组合使用。
4. **版本差异决定语法边界**：同一目标在 C++98 需要模板技巧，在 C++11 用 lambda，在 C++14/17 更简洁。
