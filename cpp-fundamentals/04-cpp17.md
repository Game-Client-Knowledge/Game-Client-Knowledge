# C++17 新特性

## 1. std::apply

### 1.1 是什么

C++17 引入，把 **tuple 的元素展开成函数的实参**：

```cpp
auto add = [](int a, int b, int c) { return a + b + c; };
std::tuple t{1, 2, 3};

std::apply(add, t);   // -> add(1, 2, 3)，编译期自动解包
```

### 1.2 实现思路

编译期包展开：按 tuple 元素顺序生成调用实参，并保持正确类型与引用语义（左值/右值按 `std::get` 转发）。

展开动作在编译期完成，生成的调用与手写实参的直接调用等价，没有运行时解释。

### 1.3 与 std::bind 的联系

`std::bind` 内部同样把绑定参数存进 tuple，调用时按占位符位置展开重组——**apply 是这种"tuple 解包调用"的通用工具**：

| 工具 | 职责 |
|---|---|
| `std::apply` | 把 tuple 原样展开成函数实参（不重排） |
| `std::bind` | 存绑定参数 + 占位符，展开时按占位符编号重排 |

### 1.4 典型用途

- 泛型代码中把不定参数打包成 tuple 后统一调用。
- 将运行期选定的参数组（存于 tuple）转发给编译期固定签名的函数。
- 配合 `std::make_tuple`、结构化绑定，实现参数收集与展开的对称操作。

### 1.5 注意

- `std::apply` 展开的是 **tuple**；普通数组或自定义元组类型需实现 tuple 协议（`std::tuple_size`、`std::get` 等）才能使用。
- 展开结果类型必须与函数签名匹配，否则编译报错。
