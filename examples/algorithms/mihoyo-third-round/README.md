# 三面算法示例

## 1. 内容

`main.cpp` 包含：

- BST 前序序列化与 O(n) 反序列化。
- 二维 0/1 矩阵最大全 1 矩形。
- 基于 `assert` 的往返和结果测试。

## 2. 编译运行

在本目录执行：

```bash
c++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o third-round-algorithms
./third-round-algorithms
```

预期输出：

```text
All third-round algorithm tests passed.
```
