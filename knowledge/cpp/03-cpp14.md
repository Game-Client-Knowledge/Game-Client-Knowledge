# C++14 新特性

## 1. 通用 Lambda（Generic Lambda）

### 1.1 是什么

C++14 允许 lambda 用 `auto` 声明参数，其 `operator()` 变成模板，**像模板函数一样按调用参数实例化**：

```cpp
auto add = [](auto a, auto b) { return a + b; };
// 编译后等价于：
// struct {
//     template <class T, class U>
//     auto operator()(T a, U b) const { return a + b; }
// };

add(1, 2);       // 实例化 operator()<int, int>
add(1.5, 2);     // 实例化 operator()<double, int>
add(s1, s2);     // 若 string 支持 operator+ 也成立
```

### 1.2 实例化规则

与普通函数模板一致：

- **同一参数类型组合只实例化一份**，重复调用复用，不会重复编译。
- **每种不同的类型组合各生成一份独立 `operator()` 机器码**。

| 情况 | 结果 |
|---|---|
| 类型组合少、调用次数多 | 无重复，泛型 + 零虚函数开销 |
| 类型组合多、函数体大 | 代码膨胀、编译时间变长 |

### 1.3 与模板函数的差异

通用 lambda 与模板函数在实例化、重载行为上基本一致，差别在于：

- 有捕获列表，能按需捕获外层状态。
- 类型匿名、就地定义，适合配合 `std::transform`、`std::sort` 等算法。
- C++20 支持显式模板参数：`auto f = []<typename T>(T x) { return x; };`

## 2. 变量模板（Variable Template）

### 2.1 是什么

允许"变量"本身模板化：按模板参数分别实例化出独立对象。

```cpp
template <typename T>
constexpr T pi = T(3.1415926535897932385L);   // 变量模板

auto a = pi<float>;    // float 实例
auto b = pi<double>;   // double 实例
```

`pi<T>` 不是单个变量，而是一组按 T 实例化的对象。

### 2.2 为什么有用

C++03 时代常量按类型参数化只能绕行类模板静态成员：

```cpp
// C++03 的绕法
template <typename T> struct PI {
    static constexpr T value = T(3.14159...);
};
// 用起来：PI<double>::value

// C++14 直接声明
pi<double>
```

标准库的 `xxx_v<T>` 后缀就是变量模板：

```cpp
template <class T>
inline constexpr bool is_integral_v = std::is_integral<T>::value;
```

### 2.3 与函数模板、类模板静态成员的区别

| 模板化对象 | 实例化产物 | 典型场景 |
|---|---|---|
| 变量模板 | 该类型的一个常量/变量 | 数学常量、类型特征值 |
| 函数模板 | 该类型的一个函数 | 算法、转换 |
| 类模板静态成员 | 类内按类型的一份常量 | C++03 时代的替代方案 |
