# C++17 新特性

## 1. std::apply

### 1.1 是什么

C++17 引入，把 **tuple 的元素展开成函数的实参**：

```cpp
auto add = [](int a, int b, int c) { return a + b + c; };
std::tuple t{1, 2, 3};

std::apply(add, t);   // -> add(1, 2, 3)，编译期自动解包
```

### 1.2 实现思路

编译期包展开：按 tuple 元素顺序生成调用实参，并保持正确类型与引用语义（左值/右值按 `std::get` 转发）。

展开动作在编译期完成，生成的调用与手写实参的直接调用等价，没有运行时解释。

### 1.3 与 std::bind 的联系

`std::bind` 内部同样把绑定参数存进 tuple，调用时按占位符位置展开重组——**apply 是这种"tuple 解包调用"的通用工具**：

| 工具 | 职责 |
|---|---|
| `std::apply` | 把 tuple 原样展开成函数实参（不重排） |
| `std::bind` | 存绑定参数 + 占位符，展开时按占位符编号重排 |

### 1.4 典型用途

- 泛型代码中把不定参数打包成 tuple 后统一调用。
- 将运行期选定的参数组（存于 tuple）转发给编译期固定签名的函数。
- 配合 `std::make_tuple`、结构化绑定，实现参数收集与展开的对称操作。

### 1.5 注意

- `std::apply` 展开的是 **tuple**；普通数组或自定义元组类型需实现 tuple 协议（`std::tuple_size`、`std::get` 等）才能使用。
- 展开结果类型必须与函数签名匹配，否则编译报错。

## 2. 结构化绑定（Structured Bindings）

把对象成员一次性解出为具名变量：

```cpp
std::pair<int, std::string> p{42, "x"};
auto [id, name] = p;                        // id=42, name="x"

for (auto& [key, value] : map) { ... }      // 遍历 map 最常用
```

- 适用于 pair/tuple/数组与全部公开数据成员的聚合类。
- 用 `auto&` 避免拷贝，`const auto&` 只读。

## 3. if constexpr

编译期分支：只有满足条件的分支**参与编译**：

```cpp
template <typename T>
auto value_of(T v) {
    if constexpr (std::is_pointer_v<T>)
        return *v;              // T 是指针才编译这行
    else
        return v;
}
```

- 与普通 `if` 的区别：未选中的分支不实例化，写指针解引用不会让非指针类型报错。
- 用直白的 if/else 替代部分 SFINAE 与标签分派，模板代码更可读。

## 4. 常用新增库组件

| 组件 | 用途 |
|---|---|
| `std::string_view` | 只读字符串视图，不拥有内存；参数传递与解析时避免拷贝 |
| `std::optional<T>` | 可能不存在的值，替代哨兵值与"空指针表示无值" |
| `std::variant<...>` | 类型安全 union，可存放若干类型之一 |
| `std::any` | 任意类型的单值容器，运行期类型擦除 |

注意：`string_view` 不保证以 `'\0'` 结尾，且底层数据必须在视图存活期内有效。

## 5. 其他语言特性

| 特性 | 说明 |
|---|---|
| CTAD（类模板实参推导） | `std::pair p{1, 2.0};` 自动推导模板实参 |
| 折叠表达式 | `(args + ...)` 展开参数包，配合可变参数模板 |
| `inline` 变量 | 头文件定义变量不违反 ODR |
