# 游戏客户端八股分类

## 1. 优先级说明

本文使用以下优先级：

| 级别 | 含义 |
|---|---|
| P0 | 几乎所有游戏客户端岗位都应掌握 |
| P1 | 常见追问，取决于项目和引擎 |
| P2 | 专项岗位或中高级岗位重点 |

“八股”不应只背定义。每个知识点至少准备：

```text
定义
-> 底层原理
-> 常见方案对比
-> 适用场景
-> 项目中的真实例子
```

- 如何定位 GC Spike？
- 多线程优化为什么可能变慢？
- 战斗场景性能排查如何从 Profiler 热点逐步定位到渲染、物理或 CPU 问题？
- 碰撞检测如何用 BVH 或空间划分优化，更新动态物体时要注意什么？

### 11.2 GPU

| 优先级 | 核心知识 |
|---|---|
| P0 | Draw Call、SetPass、Overdraw |
| P0 | 顶点量、像素填充、纹理带宽 |

| P1 | RenderTexture、后处理、阴影 |
| P2 | GPU Capture 与硬件计数器 |

典型问题：

- 一个场景中有一百个相似角色时，如何选择合批、GPU Instancing 或其他渲染方案？
- 如何通过 CPU 预裁剪减少视锥体外物体的 Draw Call，什么时候可能得不偿失？
- 低端手机出现发热和降频时，如何区分持续负载、功耗和 GPU/CPU 瓶颈并制定优化策略？
