# 游戏客户端面试知识体系

## 1. 文档范围

本文档整理游戏客户端岗位常见的基础知识题、原理题、架构题和项目追问。

适用方向包括：

- Unity 客户端。
- Unreal 客户端。
- C++ 自研引擎客户端。
- 玩法与业务客户端。
- 引擎、渲染和性能优化方向。

不同公司和岗位侧重点差异很大。以下分类是复习框架，不代表所有岗位都会覆盖全部内容。

## 2. 总体分类

游戏客户端面试可以分为十二类：

```text
1. 编程语言与运行时
2. 数据结构与算法
3. 操作系统、内存与并发
4. 计算机网络
5. 游戏数学
6. 游戏引擎与客户端架构
7. 图形渲染
8. 物理与动画
9. 游戏网络同步
10. 性能优化与工程化
11. Unity、Unreal 与平台专项
12. 项目经历与系统设计
```

详细知识点和典型问题参见[游戏客户端八股分类](./01-knowledge-map.md)。

## 3. 推荐复习顺序

若目标是普通玩法客户端或 Unity/Unreal 客户端，建议：

```text
语言与运行时
-> 内存、并发和数据结构
-> 引擎生命周期与资源管理
-> 游戏数学与基础渲染
-> 网络同步
-> 性能分析
-> 项目架构与项目追问
```

若目标是引擎或渲染岗位，应提高以下内容优先级：

```text
C++
-> CPU/GPU 与内存体系
-> 线性代数
-> 渲染管线与 Shader
-> 多线程任务系统
-> 资源管线
-> 性能分析
```

## 4. 面试深度

同一个知识点通常会沿五个层次追问：

| 层次 | 面试问题 |
|---|---|
| 定义 | 它是什么？ |
| 原理 | 为什么这样工作？ |
| 对比 | 与另一种方案有什么差异？ |
| 场景 | 在什么情况下选择它？ |
| 实证 | 你在项目中如何定位、验证和优化？ |

只记定义通常不够。高质量回答应包含：

```text
结论
+ 原理
+ 适用条件
+ 代价
+ 项目例子或验证方法
```

## 5. 岗位侧重点

| 岗位 | 最高优先级 |
|---|---|
| Unity 玩法客户端 | C#、Unity 生命周期、资源管理、UI、网络、GC 优化 |
| Unreal 玩法客户端 | C++、UObject、Gameplay Framework、反射、GC、Replication |
| 自研引擎客户端 | C++、内存、多线程、资源系统、渲染、跨平台 |
| 渲染客户端 | 图形 API、GPU 管线、Shader、PBR、阴影、移动端 GPU |
| 性能优化 | CPU Cache、内存、任务系统、Profiler、GPU Bottleneck |
| 客户端架构 | 模块边界、消息系统、状态管理、资源生命周期、可测试性 |
